Task 3 – Food Waste Analytics Dashboard

Project Overview

This project presents an interactive Power BI dashboard developed to analyze food waste patterns and identify potential operational improvement opportunities.

Objectives

Monitor total and average food waste.

Analyze food waste across different waste categories.

Explore waste patterns by staff experience.

Compare food waste on special-event days and regular days.

Examine historical waste trends and operational indicators.

Tools & Technologies

Microsoft Power BI

Power Query

DAX

Food waste dataset

Key Dashboard Metrics

Total Food Waste

Average Food Waste

Total Meals Served

Food Waste per Meal

Total Records Analyzed

Deliverable

The Power BI dashboard file is available as swynex-food-waste.pbix.
